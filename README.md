# ServingSeeds website

Public website for ServingSeeds (Memphis, TN): IT services, media & production, senior care support, and education & tutoring.

Published with GitHub Pages from `index.html`. To update contact info or the Stripe payment link, edit the `SITE` block near the bottom of `index.html`.

Invoices, jobs and bookkeeping live in the private ServingSeeds Office on claude.ai, not in this public repository.
